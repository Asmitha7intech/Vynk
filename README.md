# 🚀 What is VYNK?

Finding people to build with is one of the biggest challenges students
face during hackathons, competitions, research projects, and startup ideas.

Students often depend on:

- Friends
- Classmates
- WhatsApp groups
- Department communities
- Existing social circles

This creates a problem:

> The person who could make your project significantly better may be
> someone you have never met.

**VYNK is designed to solve that problem.**

VYNK creates a student-focused collaboration ecosystem where people can
discover each other through:

**Skills + Interests + Projects + Activity + Reputation + Collaboration**

Instead of asking:

> "Who do I already know?"

VYNK asks:

> **"Who would make this team better?"**

# ✨ Core Features

| Feature | Purpose |
|---|---|
| 🔎 Explore | Discover students, projects, crews and mentors |
| 👤 Profiles | Showcase skills, interests and achievements |
| 👥 Crews | Create and recruit project teams |
| 🚀 Voyages | Showcase projects and build journeys |
| 📰 Campus Feed | Share updates and discover community activity |
| 🧑‍🏫 Mentors | Discover verified mentors and request guidance |
| 🏆 Leaderboard | Rank builders using XP and reputation |
| ⚡ Quests | Complete technical challenges and earn XP |
| 🔥 Streaks | Encourage consistent participation |
| 🧩 Cross-Department Discovery | Discover talent outside your department |
| 📊 Event Analytics | Capture platform activity as structured events |
